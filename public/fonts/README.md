# フォントファイルの配置手順

このディレクトリに以下の2ファイルを手動でダウンロードして配置してください。

## 必要なファイル

| ファイル名 | ダウンロード元 |
|---|---|
| `NotoSansJP-Regular.ttf` | https://fonts.google.com/noto/specimen/Noto+Sans+JP |
| `NotoSansJP-Bold.ttf`    | https://fonts.google.com/noto/specimen/Noto+Sans+JP |

## ダウンロード手順

1. 上記URLにアクセス
2. 右上の「Download family」をクリック
3. ZIPを解凍すると `NotoSansJP-Regular.ttf` と `NotoSansJP-Bold.ttf` が含まれています
4. このフォルダ（`public/fonts/`）にコピーする
